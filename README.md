# Campus Bites Cafe - College Student Restaurant Website

A clean, responsive, and pocket-friendly cafe website designed specifically for college students. Built with simple, beginner-friendly **HTML5** and **CSS3** (Flexbox & Grid).

**Developed for**: CA Web Development Project 1 (1st Year College Submission)

## 💡 Key Features for 1st Year Viva / Evaluation

1. **Semantic HTML5**: Organized with `<header>`, `<nav>`, `<section>`, and `<footer>` tags.
2. **Simple, Clean CSS3**:
   - Flexbox used for navbar and about section alignment.
   - CSS Grid used for responsive menu item cards.
   - Media queries (`@media (max-width: 768px)`) for mobile and tablet adaptation.
3. **Interactive Features**:
   - Filter menu items by category (All, Snacks, Pizzas, Drinks, Desserts).
   - Quick order tray calculating real-time bill in ₹.
   - Table reservation form with date validation and instant popup confirmation.
   - Mobile hamburger menu toggle.

## 🚀 How to Run Locally

Open terminal in this directory and start a local server:
```bash
python3 -m http.server 8080
```
Open your browser at: `http://localhost:8080`
